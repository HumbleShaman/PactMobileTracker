# Fonts

`heros-400.woff2` and `heros-700.woff2` are Latin subsets of **TeX Gyre Heros** (regular and bold, version 2.004) by the GUST e-foundry, converted to WOFF2 with fontTools. TeX Gyre Heros is distributed under the [GUST Font License](https://www.gust.org.pl/projects/e-foundry/licenses); the original fonts are at https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros.

The live view lists them after Helvetica Neue, so Apple devices use their own Helvetica Neue and these files only download where it is missing (Windows).
